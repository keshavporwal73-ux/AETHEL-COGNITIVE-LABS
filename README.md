### Method 2: Import via Vercel Dashboard

1. Log into your [Vercel Dashboard](https://vercel.com/dashboard).
2. Click **Add New…** → **Project**.
3. Under **Import Git Repository**, select `keshavporwal73-ux/AETHEL-COGNITIVE-LABS` (or search for it).
4. Vercel will automatically detect the **Vite** framework preset with:
   - **Framework Preset**: `Vite`
   - **Build Command**: `vite build`
   - **Output Directory**: `dist`
5. *(Optional)* Add the following **Environment Variables**:
   | Variable Name | Description | Default / Example |
   | ------------- | ----------- | ----------------- |
   | `VITE_SUPABASE_URL` | Supabase Project URL | `https://ecrfkktaobfcpxkalkzo.supabase.co` |
   | `VITE_SUPABASE_ANON_KEY` | Supabase Anonymous Key | *(Your Supabase anon key)* |
   | `VITE_APP_ID` | Application Identifier | `app-e84qhhad10xt` |
6. Click **Deploy**. Your application will be live with full SSL and global CDN!

# 4. Deploy to Production
